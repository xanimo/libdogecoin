## Introduction

Libdogecoin's wallet API exposes access to the wallet files produced by `spvnode`. `spvnode` initializes and updates a local wallet database (`<chain>_wallet.db`, e.g. `main_wallet.db`) while syncing the chain and recording transactions relevant to watched addresses. This API reads that same wallet database so applications can query tracked address state and spendable UTXOs without re-implementing wallet storage.

Typical uses include monitoring balances and assembling transaction input metadata (txid, vout, amount) for backend payment processors, lightweight wallet frontends, and transaction builders.

The API is address-scoped: you pass an address, the API selects the matching chain from the address prefix, opens the corresponding `<chain>_wallet.db` in the current working directory, and returns data associated with that address.

## Wallet Query Flow

Most integrations use this sequence:

1. Run `spvnode` (e.g. `spvnode -a <address> scan`) to create and populate the wallet database.
2. From the application, register or load the address through the wallet API.
3. Query how many UTXOs are currently available.
4. Read each UTXO's txid, vout, and amount.
5. Read current total balance for display or spend planning.

This flow is mirrored in the per-function examples below and in the end-to-end example at the bottom of this document.

## Wallet Access API

These functions open the SPV-generated wallet database and manage the set of watched addresses tracked within it.

---

### **dogecoin_wallet_read**

`dogecoin_wallet* dogecoin_wallet_read(char* address)`

Opens the wallet database that corresponds to the address's chain (e.g. `main_wallet.db` for mainnet addresses) and returns a wallet handle, or `NULL` on failure. The address's base58 prefix is used to select the chain; the wallet file itself is the one generated by `spvnode`.

_C usage:_

```C
dogecoin_wallet* wallet = dogecoin_wallet_read("DYourAddressHere");
if (!wallet) {
    // handle read failure
}
```

---

### **dogecoin_register_watch_address_with_node**

`int dogecoin_register_watch_address_with_node(char* address)`

Registers an address with the running node so transactions touching that address are tracked.

_C usage:_

```C
if (!dogecoin_register_watch_address_with_node("DYourAddressHere")) {
    // handle registration failure
}
```

---

### **dogecoin_unregister_watch_address_with_node**

`int dogecoin_unregister_watch_address_with_node(char* address)`

Unregisters a previously watched address from node tracking.

_C usage:_

```C
dogecoin_unregister_watch_address_with_node("DYourAddressHere");
```

## Wallet Query API

These functions provide address-scoped UTXO and balance queries.

> Note: Index-based wallet query functions in this section use **1-based indexing**. Index `0` is invalid.

---

### **dogecoin_get_utxo_vector**

`int dogecoin_get_utxo_vector(char* address, vector_t* utxo_vec)`

Populates a caller-provided vector with UTXO entries for the address.

_C usage:_

```C
vector_t utxo_vec;
vector_init(&utxo_vec, sizeof(dogecoin_utxo), NULL);
dogecoin_get_utxo_vector("DYourAddressHere", &utxo_vec);
```

---

### **dogecoin_get_utxos**

`uint8_t* dogecoin_get_utxos(char* address)`

Returns serialized UTXO data for the address.

_C usage:_

```C
uint8_t* utxos_blob = dogecoin_get_utxos("DYourAddressHere");
if (!utxos_blob) {
    // handle missing UTXO payload
}
```

---

### **dogecoin_get_utxos_length**

`unsigned int dogecoin_get_utxos_length(char* address)`

Returns the number of UTXOs available for the address.

_C usage:_

```C
unsigned int utxo_count = dogecoin_get_utxos_length("DYourAddressHere");
printf("utxos: %u\n", utxo_count);
```

---

### **dogecoin_get_utxo_txid_str**

`char* dogecoin_get_utxo_txid_str(char* address, unsigned int index)`

Returns the UTXO transaction ID as a hex string at the provided index.

_C usage:_

```C
char* txid_hex = dogecoin_get_utxo_txid_str("DYourAddressHere", 1);
if (txid_hex) {
    printf("utxo #1 txid: %s\n", txid_hex);
}
```

---

### **dogecoin_get_utxo_txid**

`uint8_t* dogecoin_get_utxo_txid(char* address, unsigned int index)`

Returns the raw transaction ID bytes for the UTXO at the provided index.

_C usage:_

```C
uint8_t* txid_raw = dogecoin_get_utxo_txid("DYourAddressHere", 1);
if (!txid_raw) {
    // handle missing txid bytes
}
```

---

### **dogecoin_get_utxo_vout**

`uint32_t dogecoin_get_utxo_vout(char* address, unsigned int index)`

Returns the output index (`vout`) for the UTXO at the provided index.

_C usage:_

```C
uint32_t vout = dogecoin_get_utxo_vout("DYourAddressHere", 1);
printf("utxo #1 vout: %u\n", vout);
```

---

### **dogecoin_get_utxo_amount**

`uint64_t dogecoin_get_utxo_amount(char* address, unsigned int index)`

Returns the UTXO amount in koinu for the entry at the provided index.

_C usage:_

```C
uint64_t amount_koinu = dogecoin_get_utxo_amount("DYourAddressHere", 1);
printf("utxo #1 amount (koinu): %llu\n", (unsigned long long)amount_koinu);
```

---

### **dogecoin_get_balance**

`uint64_t dogecoin_get_balance(char* address)`

Returns the address balance in koinu.

_C usage:_

```C
uint64_t balance_koinu = dogecoin_get_balance("DYourAddressHere");
printf("balance (koinu): %llu\n", (unsigned long long)balance_koinu);
```

---

### **dogecoin_get_balance_str**

`char* dogecoin_get_balance_str(char* address)`

Returns the address balance as a string.

_C usage:_

```C
char* balance_str = dogecoin_get_balance_str("DYourAddressHere");
if (balance_str) {
    printf("balance: %s\n", balance_str);
}
```

## End-to-end Example

```C
char* address = "DYourAddressHere";
unsigned int utxo_count = dogecoin_get_utxos_length(address);

// Wallet query API uses 1-based indexing for UTXO lookups.
for (unsigned int i = 1; i <= utxo_count; i++) {
    printf("txid:   %s\n", dogecoin_get_utxo_txid_str(address, i));
    printf("vout:   %u\n", dogecoin_get_utxo_vout(address, i));
    printf("amount: %llu koinu\n", (unsigned long long)dogecoin_get_utxo_amount(address, i));
}

printf("balance: %s\n", dogecoin_get_balance_str(address));
```

> Note: UTXO index values are 1-based in this API (`i` starts at `1`, and `utxo_count` comes from `dogecoin_get_utxos_length`). For empty wallets (`utxo_count == 0`), the loop is intentionally skipped.
